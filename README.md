# 2048 PWA

Классическая игра 2048 как Progressive Web App.

## Возможности
- 🎮 Режимы: 3×3, 4×4, 5×5, 6×6
- 🎨 6 тем: светлая, тёмная, нейтральная, океан, сепия, лес
- ↶ Отмена хода (до 20 шагов)
- 💾 Автосохранение игры при выходе
- 🏆 Таблица лидеров (топ-50)
- 👤 Персональный логин игрока
- 📱 Адаптивный интерфейс + свайпы на мобильных
- 📲 PWA — установка на телефон/десктоп

## Управление
- **ПК:** стрелки или WASD, `Ctrl+Z` — отмена хода
- **Мобильные:** свайпы

## Хранение данных
Всё хранится локально в `localStorage`:
- `game2048_v1` — текущая игра
- `game2048_settings_v1` — настройки и логин
- `game2048_leader_v1` — рейтинг
